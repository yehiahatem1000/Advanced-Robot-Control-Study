Lecture Summary

Advanced Robot Control

1. Introduction

Robot control means generating commands that make a robot move accurately, smoothly, and safely. Basic PID controllers reduce the difference between desired and actual position, but modern robots may have nonlinear dynamics, coupled joints, changing payloads, friction, disturbances, and model uncertainty.

Tracking goal: x(t) → xd(t)
Joint error: e = qd − q

Here, xd is the desired state/trajectory, x is the actual state, qd is the desired joint position, and q is the measured position.

2. Control Architecture

  • Task planner: defines what the robot should do.
  • Trajectory generator: converts the task into desired positions, velocities, and accelerations.
  • Controller: compares desired values with sensor measurements and calculates the control action.
  • Actuators and robot: execute the commands; sensors measure the result.
Desired Trajectory → Controller → Actuators → Robot → Sensors → Feedback

The loop runs continuously, often every few milliseconds.

3. Computed-Torque Control (CTC)

CTC uses the robot's mathematical dynamic model to compensate for nonlinear effects and improve trajectory tracking.

M(q)q̈ + C(q,q̇)q̇ + G(q) + F(q̇) = τ
  • M(q): inertia matrix.
  • C(q,q̇): Coriolis and centrifugal effects.
  • G(q): gravity.
  • F(q̇): friction.
  • τ: joint torque.

Strength: excellent tracking when the model is accurate. Limitation: model errors can reduce performance.

4. Adaptive and Robust Control

  • Adaptive control: estimates uncertain parameters online and adjusts controller parameters based on observed behavior. Useful when payloads or mechanical properties change.
  • Robust control: aims to maintain acceptable performance despite uncertainty, without necessarily estimating it explicitly. Useful when disturbances and model errors are difficult to predict.

Remember: Adaptive = learn/adjust; Robust = tolerate uncertainty.

5. Sliding-Mode Control (SMC)

SMC is a nonlinear method designed for strong robustness against disturbances and model uncertainty. It drives the system toward a sliding surface.

s = ė + λe, where λ > 0

Once the system reaches the sliding surface, tracking error converges toward zero. Its main limitation is chattering: rapid switching that can cause actuator vibration and mechanical stress. Boundary layers or continuous approximation functions can reduce it.

6. Disturbance Rejection

Disturbances include friction, external forces, payload changes, sensor noise, and unexpected contact. A disturbance observer estimates unknown disturbances; the controller then generates a compensating action to maintain tracking.

7. Controller Comparison

  • PID: simple and easy to implement, but limited with nonlinear dynamics.
  • CTC: excellent model-based tracking, but requires an accurate model.
  • Adaptive: handles changing parameters, but adds computational complexity.
  • Robust: handles uncertainty, but needs careful design.
  • SMC: strong disturbance robustness, but may cause chattering.
  • Disturbance rejection: compensates external disturbances, but requires suitable estimation.

8. Conclusion and Applications

Advanced control improves accurate, stable, and reliable robot motion under nonlinear dynamics, uncertainty, disturbances, and changing conditions. Applications include industrial manipulators, collaborative robots, autonomous systems, and medical robotics.

Quick revision: CTC → accurate model-based tracking · Adaptive → adjusts parameters · Robust → tolerates uncertainty · SMC → strong robustness but possible chattering · Disturbance observer → estimates and compensates unknown disturbances.
